# Minesweeper Game

A simple game of Minesweeper built with plain HTML, CSS and JavaScript. This is a personal project I made for fun and to practice web development.

## Built with
- HTML
- CSS
- JavaScript (no libraries or frameworks)

## Features
- 9×9 board with 10 mines
- Your first click is always safe
- Empty areas open up automatically
- Flag squares you think are mines
- Mine counter that updates as you place flags
- Win and lose messages
- New game button to start over

## Project structure
```
minesweeper/
├── index.html   # page structure
├── style.css    # styling
└── script.js    # game logic
```
